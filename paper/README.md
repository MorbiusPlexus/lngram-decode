# Paper

`main.tex` is an ACL-format (review mode, anonymous) paper. `references.bib` holds the bibliography, and `figures/*.pdf` is generated by `make_figures.py` from `../results/`.

## Compile

- **Overleaf:** create a project from the official *ACL Rolling Review / ACL 2026* template. Upload `main.tex`, `references.bib` and the `figures/` folder, replacing the template's main file.
- **Local:** download `acl.sty` and `acl_natbib.bst` from https://github.com/acl-org/acl-style-files into this folder, then run:

  ```
  pdflatex main && bibtex main && pdflatex main && pdflatex main
  ```
